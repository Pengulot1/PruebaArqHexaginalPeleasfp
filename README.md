# MinijuegoPeleasFp
Un proyecto pequeño con arquitectura hexagonal, que usa swagger para sus pruebas.
se guarda en local las id de los peleadores
esta a base de solo endpoints 
el calculo seria el siguiente: 
( el peleador por ( x)  el daño del peleador por + el daño del arma por la durabilidad que esto sea multiplicado por un numero random del 0.5 al 2 incluyendo decimales de maximo dos cifras decimales  menos (-) la vida del enemigo y luego compararas esos dos valores y  tienes que devolver el que tenga mayor como ganador)
